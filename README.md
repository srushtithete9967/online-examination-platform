# Online Examination Platform

A web-based online examination platform developed as part of an internship project. The application provides a simple and interactive interface for conducting online examinations.

## Features

* Student registration
* Online examination interface
* Question display and answer selection
* Exam submission
* Result display
* Interactive and responsive user interface

## Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and layout
* **JavaScript** – Functionality and user interaction

## Project Structure

```text
Online-Examination-Platform/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the platform through the provided interface.

## Project Purpose

This project was developed to gain practical experience in frontend web development and building interactive web applications using JavaScript.
